# BtModeSwitch

Трей-утилита для Windows, которая переключает режим Bluetooth-гарнитуры одной горячей клавишей: микрофон (HFP) ↔ прослушивание (A2DP) ↔ выключено.

## Режимы

- **Режим записи (Mic / HFP)** — подключается профиль *Bluetooth Headset and Microphone* (гарнитура + микрофон), профиль вывода *Bluetooth Advanced Audio* выключается.
- **Режим прослушивания (Listen / A2DP)** — подключается только *Bluetooth Advanced Audio*, микрофон выключен.
- **Выключено (Off)** — оба профиля отключаются.

## Как это работает

Приложение находит окно диспетчера Bluetooth-устройства (`BtMgr`) и нажимает Connect/Disconnect у нужного профиля через Win32 UI Automation (`EnumChildWindows` + `SendMessage` `BM_CLICK`). Дополнительно состояние аудио-эндпоинтов читается из реестра и управляется через Core Audio (мут).

Утилита привязана к конкретной гарнитуре: ищутся аудио-устройства, в свойствах которых встречается `BRLINK`, и окно с подписью `M54`. Для другой гарнитуры потребуется поменять `Switch.NamePart` и, при необходимости, подписи профилей в `BtMgrUi`.

## Возможности

- Настраиваемая горячая клавиша переключения режимов; двойное нажатие выключает устройство.
- Опция полного перехвата клавиши (другие программы её не получат).
- Значок в трее, всплывающие уведомления с настраиваемым временем показа.
- Автозапуск при входе в систему и автоподключение при старте.
- Окно настроек (`--settings`), реестр `HKCU`.

## Командная строка

| Аргумент | Действие |
| --- | --- |
| `--mic` | Включить режим записи (HFP) |
| `--listen` | Включить режим прослушивания (A2DP) |
| `--off` | Отключить устройство |
| `--settings` | Открыть окно настроек |
| `--status` | Вывести состояние в stdout |

Без аргументов запускается трей-приложение (единственный экземпляр, mutex `BtModeSwitch_SingleInstance`).

## Сборка

Требуется Windows и .NET Framework (достаточно `csc` из комплекта Framework 4.x — он подтягивает `System.Windows.Forms` и `System.Drawing` через `csc.rsp`):

```powershell
csc /target:winexe /out:BtModeSwitch.exe BtModeSwitch.cs
```

## Файлы

- `BtModeSwitch.cs` — исходник приложения.
- `btmgr.ps1` — вспомогательный скрипт для ручного управления тем же окном `BtMgr` через UI Automation.
- `mute.ps1` — включение/выключение мута конкретных аудио-эндпоинтов по GUID (GUID зашиты под конкретную систему).

## Ограничения

- Только Windows; окно `BtMgr` должно быть открыто и устройство в состоянии `Idle, Paired`.
- `btmgr.ps1` и `mute.ps1` содержат GUID/подписи конкретного устройства — перед использованием на другой машине их нужно заменить.
